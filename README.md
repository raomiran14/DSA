# 🌳 Data Structures & Algorithms (Java)

> Core DSA implementations in Java — the fundamentals every software engineer is expected to know cold.

[![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white)](https://www.java.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## What's Inside

**Trees**
- `BST.java` — Binary Search Tree implementation
- `BSTSEARCH.java` — Search operations on BST
- `BSTDELETION.java` — Node deletion (all three cases)

**Searching & Sorting**
- `BinarySearchSimple.java` — Binary search
- `InsertionSort.java` — Insertion sort
- `QuickSort.java` — Quick sort

## Running

```bash
javac QuickSort.java && java QuickSort
```
